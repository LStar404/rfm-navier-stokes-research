01  比较协议与参考解可信度

圆柱半径 a=0.5，外边界 R=6，Re=100，ν=0.01。由静止启动，主流采用平滑三次起始爬升；4&lt;t&lt;12 施加峰值 0.12 的横向来流脉冲。之后保留完整角向自由度，均值流由切向动量方程演化。外边界指定流函数并令涡量为零。该有限环域问题与无限域圆柱绕流有不同边界。

评分时刻固定为 t=24、36、48、54、60、66、72。三套独立面积加权网格为 Gauss123、偏移中点129和外层加密144。速度采用两分量联合 L² 范数，涡量采用实际旋度的 L² 范数，分别除以同一区域同一时刻的参考范数。全域与 r≤2.5 近场四类误差均不超过0.5%；全程未作相位对齐。

这一段局部加密链的组合差异低于预设0.125%筛查值，即门槛的四分之一。它是经验依据，不能充当相对连续 PDE 真解的严格误差上界。随后n384→448的非单调变化表明，必须继续审计高分辨率参考的数值可靠性。0.1%档的0.025%参考预算已经失败，当前不作这一档速度结论。

FD 的“四阶”指径向差分精度，角向为 Fourier；三种方法在本表中都用二阶 SBDF2 时间推进。各方法可独立选择达到误差门槛的网格与步长。这里的获胜范围是已登记的候选集合，未证明全局最优。

为何不能只看速度误差

流函数误差通过一阶导数进入速度，通过二阶导数及 k² 因子进入涡量。被截去的高频和外壁薄层会先在涡量指标暴露。相对采样参考场的离散 Fourier 投影下界表明：K72 的最坏涡量尾能量已有0.11198%，所以这个角向空间不可能达到0.1%。K88 与 K96 的对应下界约0.02741%与0.01319%，为下一轮选型提供依据。

每次重新构造模型、分解与预收缩算子，重新初始化运行时、上传数组、建立 FFT 计划和图；计时覆盖最后同步、结果返回和资源清理。各阶段中位数之和不必等于总耗时中位数。这是同一 Python 进程内的新建求解器，未清除解释器、驱动磁盘编译缓存；不能称为操作系统级冷进程测量。

FP64 状态、历史量、算子和输出常驻显存，24 步图执行批量提交。质量投影、非线性投影与隐式算子在设置阶段预收缩。完整9216步轨迹与对应 CPU 的状态和探针差异，RFM 最多1.09×10⁻⁹，Legendre 最多1.75×10⁻¹⁰。

FFT 次数与同步的实际变化

本轮仍有9215次非线性评价，每次三组逆变换和两组正变换。图执行降低提交、分配和同步开销，没有减少数学上的 FFT 次数。Legendre 得到相同的驻留、预收缩和图执行优化，因此这项收益应归于实现。

CuPy 路径在完整轨迹上数值一致，但并发试跑约23.22秒；其当前批量矩阵调用拒绝图捕获。原生驱动、cuFFT 与自定义内核的完整路径因此被保留。该负面结果只适用于测试的软件版本和实现，不能推广为库的一般性能结论。

04  理论与实际算子的对应

令 s=log(r/a)。非零模态速度取 u<sub>r</sub>=ψ<sub>θ</sub>/r、u<sub>θ</sub>=−ψ<sub>s</sub>/r，再加平均切向速度 v₀(s)。解析散度中的混合导数抵消。RFM 与 Legendre 都继承这个结构，不可压性不是随机特征独有。

离散质量形式为 M<sub>k</sub>=Σw(f<sub>s</sub>f<sub>s</sub><super>T</super>+k²ff<super>T</super>)，扩散形式为 K<sub>k</sub>=νΣw(f″−k²f)(f″−k²f)<super>T</super>/r²。正权求积与保留采样秩给出正定质量和半正定扩散；A<sub>k</sub>=1.5M<sub>k</sub>+ΔtK<sub>k</sub> 可解。正定性本身不保证求积精度或好的条件数。

齐次自对流配对中，非零模态留下 ∫r²v₀u<sub>r</sub>ω；均值动量的 −平均(u<sub>r</sub>ω) 配对恰好抵消。该恒等式要求公共节点、公共权重、相同状态、相容投影与 N&gt;3K 的二次去混叠。非齐次边界提升仍可做功。

预收缩 B=A⁻¹M、G=A⁻¹T 将矩阵乘法和隐式更新合并；精确算术下等价，有限精度下检查 AB−M、AG−T 和完整轨迹。实际结果支持当前配置的等价性，未证明任意病态配置都安全。

全离散稳定性尚未证明

SBDF2 使用外推非线性 2F(c<sub>n</sub>)−F(c<sub>n−1</sub>)，它与新状态的功不等于齐次自对流功。因此不能从半离散抵消推出无条件稳定。旧 SBDF3 两档试跑在 t=2 与2.75 产生非有限值，未被晋升。现阶段的稳定性证据来自指定步长下的完整轨迹和独立时间加密。

这些是每批12个真实 RFM、Legendre、FD 混合任务的完成率，含进程启动。12进程明显提高短批吞吐量；延长积分后，1与2个 NumPy BLAS 线程的样本范围重叠，最优线程数尚不稳健。正式单任务计时停止这些竞争工作。利用率只作辅助，不通过空转增加占用。

外边界不确定性大于本轮数值门槛

独立加密的 R=8 计算中，涡脱落 Strouhal 数约0.1737015，R=6约0.1755584。R=8 自身加密的最坏全域涡量变化约0.02669%；两域在公共 r≤4 区域的未对齐涡量差最大约50.39%。长时相位差会放大这一指标，它同时提醒我们：0.5%的数值误差控制并未消除有限外边界影响。

本文的计时结论仅适用于这些明确的有限边界、二维层流和参数。未完成无限域外推，也未据此推断三维、高雷诺数湍流或一般复杂几何上的方法优势。

较有希望的贡献是：边界层相容的 Galerkin 离散、可核查的能量结构，以及完整 FP64 CUDA 求解器。要形成可信论文，还需补齐更快 FD 基线下的比较、多个规模的收益趋势、一个检验适用边界的补充算例、独立复现与完整版本归档。随机特征相对 Legendre 的优势仍应由数据决定。
