一次变步 SBDF2 桥接与本算例的验证范围

固定策略在 t=8 将步率由 128 改为 112。令 H=1/128，h=1/112，r=h/H=8/7。
相邻三个时刻是 t_- = 8-H，t_0 = 8，t_+ = 8+h。x 是齐次边界基系数，
g 是给定的一阶角向边界幅值，M_l 和 K_l 分别是边界提升的质量与扩散投影。
物理弱质量为 m=Mx+g M_l。半离散方程是 m' + Kx + g K_l = f，
其中 K 采用正耗散符号，f 是外推的非线性弱投影。

1. 桥接系数

对三点二次插值在 t_+ 求导，乘以 h 得到

  h Dm = a0 m_+ - b0 m_0 + b1 m_-
  a0 = (1+2r)/(1+r) = 23/15
  b0 = 1+r = 15/7
  b1 = r²/(1+r) = 64/105

两点一次外推在 t_+ 给出 f_ext = (1+r) f_0 - r f_-。
移项后的线性方程为

  (a0 M+h K) x_+ = b0 m_0 - b1 m_- + h f_ext - g_+ (a0 M_l+h K_l).

历史质量已经包含各历史时刻的提升，未来提升只减一次。零模态使用独立的实数均值
动量质量与扩散矩阵，非线性项为负径向投影，没有直接提升项。
首步保持原静止初值的隐式 Euler。桥后的第一个等步更新使用 x_+ 与 x_0 两份历史，
此时两段相邻间隔均为 h。r=1 的系数还原为原等步 SBDF2 和显式二步外推。

2. 与现有矩阵路径的对应

现有构造器的质量系数固定为 3/2。令 s=(3/2)/a0=45/46，使用有效构造步长 s h，
则 A_eff=(3/2)M+s h K=s(a0 M+h K)。桥接组合的物理右端乘 s 后进入原 advance，
其现有未来提升也恰好乘了 s。CPU 预收缩保存的两份值依赖其各自的 A^{-1}。
桥接从最后两份原始非线性谱分别生成桥接预收缩值，再将 t_0 的谱投影到新的等步
因子下，用于桥后的第一个等步更新。CPU 原始投影路径的历史质量和通量与步长无关，
可以直接保留。两者都沿用原边界幅值、均值项和角向去混叠。

3. 局部一致性与这一时间网格的零方程检验

在 t_+ 附近平滑且 r 有界时，导数近似误差的首项为 -h(h+H)m'''(t_+)/6，
显式外推误差的首项为 -h(h+H)f''(t_+)/2。因而一次桥接保留二阶局部一致性。
对零方程 y'=0，设差分 Δ_+ = y_+-y_0 和 Δ_0=y_0-y_-，由 b0=a0+b1 得到

  Δ_+ = [r²/(1+2r)] Δ_0 = (64/161) Δ_0.

其余步的因子均为 1/3。由此直接得到本次分段网格的齐次差分有界性。该标量检验
只覆盖零方程和指定的时间网格。实际 NS 的输运、扩散、边界强迫及模式耦合仍须在
完整轨迹上用物理误差门槛和实现一致性门槛分别检查。变步 BDF 在其他扰动范数下
可以有不同的稳定结果。不可压 NS 的已有显式 IMEX 有限元分析还依赖其离散的 CFL 条件。

变步 BDF2 零方程的差分分解见 Söderlind、Fekete 与 Faragó 的第 4 节。
https://link.springer.com/article/10.1007/s10543-018-0716-y

不同扰动范数下的稳定性分析见 Li 与 Liao。
https://epubs.siam.org/doi/10.1137/21M1462398

显式变步 IMEX 不可压 NS 有限元误差分析见 García-Archilla 与 Novo。
https://idus.us.es/items/d64e6df6-c0bb-44de-bd83-3f0f413b7d54

4. 固定方程与 CPU 试跑

固定随机系数的首轮筛查曾超过 2e-10 前向门槛。65 位十进制求解重建的同一 FP64
矩阵和物理右端后，RFM 随机 k=63 的矩阵二范数条件数约 1.31e7。原显式逆应用
的相对前向误差约 5.72e-9，同矩阵直接 FP64 求解约 1.33e-11。实际 t=8 相邻状态
在 RFM 的 k=1 上，原始与预收缩桥接相对误差约 3.88e-13 和 4.22e-13。选定的
弱高频 k=56 约 2.8e-10。随机系数与真实相邻流场分别保存，比较范围只含选定模态。

CPU 两个实现各在 RFM7331 与 Legendre17 上跑到 t=72。所有 t≤8 的保存状态和
探针逐位匹配同实现的原步率 128 轨迹。三网格、21 个共同保存时刻的两 CPU 实现
最大相对场差为 3.42e-10，最大探针差为 3.76e-10。这两项是实现误差。

实际每条轨迹进行 8192 步，调用 8191 次非线性核，较全程步率 128 的 9215 次少
1024 次，即 11.11%。每次核含一次三场逆变换批和一次两场正变换批，共少 2048 次
批调用。该数字衡量积分工作量，CPU 试跑计时属于并发诊断。

固定状态审计和保存轨迹位于 cpu_sbdf2_switch_pilot_output。
