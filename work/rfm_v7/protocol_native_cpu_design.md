# CPU 算子改写与语言对照

以 RFM37 和 Legendre37 的完整 t=72 轨迹做四臂 CPU 消融。四组分别使用 FullGalerkin、BufferedGalerkin、StridedGalerkin 和 RecurrenceGalerkin。每个区组固定 RFM 种子、离散参数、步率、参考和探针，只随机化八个求解顺序。三条相邻对比依次测径向缓冲、隐式布局和基函数递推。后者改变初始化与场重建，对 RFM 只替换均值多项式，对 Legendre 同时替换非零模态多项式。求解内外分别记录总耗时、初始化与推进加观测。当前方案未运行。

## 当前实现与改写目标

| 路径 | 已有原生计算 | 仍可改的边界 |
|---|---|---|
| CPU Galerkin | NumPy 的批量矩阵乘，SciPy 的实 FFT，原生线性代数 | Python 逐步调度，SBDF2 右端多项表达式的临时数组，每步质量与通量数组，实虚布局和 FFT 输出分配 |
| CPU FD | C 的缓冲径向 stencil 和物理乘积，C 的带状 LU 应用，SciPy 的实 FFT | 每步转置填充、FFT 输出、质量副本与历史右端仍由 Python/NumPy 组织 |
| GPU Galerkin 与 FD | CUDA 原生核、持久显存、cuFFT 批计划、24 步 CUDA Graph | FP64 原生投影、径向 stencil、FFT 批布局、FD 稠密线性算子，及独立的运行时创建开销 |

旧 CPU 短程剖析显示 Galerkin 的 FFT 约占推进的 29%，隐式应用约 26–27%，径向生成与稠密乘法约 25–27%。显式 NumPy 构造约 4%。剩余的驱动与剖析残差约 3–4%，包含计时开销。该分解来自较早的 BufferedGalerkin，只用于定位，不能代表 RecurrenceGalerkin 的当前时间分摊。近期正式计时中，CPU RFM37 与 Legendre37 的初始化分别约 0.014 和 0.015 秒，整程约 8.69 秒。

## CPU 分两步测量

1. 保留现有 FFT 和隐式代数，先增加独立的缓冲驱动。为质量、通量各保留两个历史槽，加一个当前槽，按 SBDF2 消费顺序轮换。预分配右端、乘法工作区、检查点、探针输出。右端允许消耗性地扣除边界升举，历史和已保存状态不可被覆盖。第一步、末步、零模态、非齐次脉冲、异常退出都必须与已验证驱动一致。这一阶段隔离复用数组的收益。
2. 如分配与跨语言调用仍占可测比例，提供一次调用完成整个 SBDF2 时间循环的 C ABI。Python 保留离散构造、实验调度与评分。运行端持有 FFT 计划和对齐缓冲，复用同一个显式工作区和固定批次。C 与 Rust 使用同一个 FFT 后端、精度、编译优化级别、线程数、模式布局、矩阵乘算法及探针采样。避免把更换 FFT 库、启用 FMA、修改模式布局的差异归于语言。先保留 C 基线，等 Rust 工具链可用再增加同算法对照。

同样的数学离散先做固定状态、真实动态右端、非零脉冲及完整轨迹检验。代数顺序相同的缓冲改动优先要求逐位一致。更换 FFT 后端或重排浮点运算时，先以完整物理场和探针的实现差检查，再应用三网格、七时刻、四误差指标的 0.5% 门槛。隔离计时按区组报告原始值、中位数和范围。对 C 与 Rust 的语言比较使用相同的 FFT 库。对新 FFT 库或更换 BLAS 路径的效果单独列一臂。

## GPU 改写对象

三次 t=72 图内剖析中，Galerkin 投影与推进约 39 微秒，径向生成约 25–26 微秒，逆 FFT 约 25 微秒，正 FFT 约 19–21 微秒。FD 的逆 FFT 约 62 微秒，稠密隐式应用约 50 微秒。事件间隔包含 GPU 调度与 Windows 驱动影响，不能用这些数相加复原真实步长，也不能减去固定空事件间隔得到纯核时间。

- Galerkin 先比较当前 FP64 点积和按角模态分组的状态及通量共享加载。预收缩矩阵保持不变，先测复用，再测改变归约树。用原方程残差和轨迹验证后者。
- 保持角向 `N > 3K`，独立检查 cuFFT 在等价填充长度和批布局上的吞吐。以 K72 的现有 N225 为控制，可筛选 N224、240、256。在当前批次下选最小的实测端到端耗时。固定同一径向离散、时间步和保留模式，检查随机高频输入的保留系数以及完整轨迹。
- FD 的已验证 GPU 路径以稠密逆应用换取并行，代价是随径向阶数平方增长的算子储存。可对照当前实现与小块复用右端的稠密实现。新的带状并行实现需单独审查主元、原方程残差和高分辨率轨迹，不能仅用运算量估计加速。

CUDA Graph 已把多数主机调用合并。实际同档 RFM37 的逐步提交和图提交中位数约 1.499 与 1.306 秒，FD176 约 2.831 与 2.807 秒。改变宿主语言不会改变 cuFFT 或 CUDA 核的指令。复用 CUDA 上下文与编译模块的收益应与求解核收益分开评估。
