# Re=100 圆柱绕流的同门槛 GPU 复测方案

研究仍处于资格准备阶段。新计时方案预登记 65 个槽位。现有记录仅含 CPU 上的运输和审核测试，正式 GPU 计时与本方案的完整轨迹资格尚未执行。

| 分辨率 | 随机特征空间 | 同秩 Legendre | 较小 Legendre | 四阶有限差分 | 五区组总数 |
|---|---|---|---|---|---:|
| 中档 | RFM37，保留秩 39，K72/q66 | Leg35，保留秩 39，K72/q66 | 低档 Leg33 精度失败，仅留资格记录 | FD176 dense | 25 |
| 高档 | RFM41，保留秩 40，K80/q76 | Leg36，保留秩 40，K80/q76 | Leg35，保留秩 39，K80/q76 | FD176 dense 和 FD184 band | 40 |

每种 Galerkin 配置各含 uniform 和 t=8 切换的 combined。中档 128→112，高档 152→136。uniform 使用对应启动步率运行完整轨迹。combined 同时改变步率和共享的准备方式，所以该对比估计整套调度和准备的收益。RFM 每一区组在两种调度上使用同一既定种子。Legendre 固定种子 17，FD 无随机基。高档同秩比较控制保留秩、K、q 和时间调度，结果限于现有基和五个种子。更小的高档 Leg35 独立参加 0.5% 比较。两个窗口都保留 FD176，使高档候选仍与已合格的较便宜传统方法同期配对。高档 FD184 提供细化对照，同时包含线性求解布局的变化。

两窗口使用原 CUDA 11.8、FP64、相同去混叠、同一 warp 探针观测器和同一无资格/报告依赖的 solver-only 导入入口。所有方法都运行完整 T=72，保存 19 个物理时刻和 577 个探针点。完整资格另保存 combined 的两个桥后格点，共 28 个唯一 GPU 路径身份。每个身份必须通过两份独立参考的三网格四范数、0.5% 物理误差和参考预算，combined 另查同空间的 uniform 三角上界。对 CPU 同方法的场和探针要求 10⁻⁵，匹配旧 serial CUDA 保存状态要求逐位相同，完整探针变化同时要求相对和绝对尺度误差小于等于 10⁻¹²。现有测量只能提供对照，正式冻结由实际 stock 入口的完整资格解锁。

每次用独立进程创建 CUDA context。内部时钟覆盖全部准备、编译加载、计划、图捕获、推进、探针、同步、下载、释放 context 和 model；空间指纹另计入 fresh-process 时钟。fresh-process 从 Popen 前量至父进程收到原子 RETURN，含导入和文件握手；轨迹在 SAVE 后写盘。CPU 模拟的两次 RETURN 握手观测延迟为 13.0 和 14.9 ms，其中含标记写入及调度，正式时钟保留这部分。操作系统和驱动既有缓存随实际环境，测试不会人为清除。

每窗口沿用既定 sampled isolation 的两次 10 秒预检、GPU 端点 5%、1 秒进程轮询、2.5 秒最大样本间隙、10 秒 CPU 阈值和 720 秒最长活动窗口。超时终止只作用于原始 Popen 句柄，先查终态再关闭相关 I/O，保留原证据，随后停止队列。没有清洁且完整的数值复核就只给诊断状态。独立验收逐条核原始时钟、请求、所有状态和完整探针数组，另重建首区组的三网格流场。稳定速度主张需两个时钟都满足五组全胜且中位倍率至少 1.05。每组的时间范围和阶段耗时单列，编译加载属于 runtime init 的子项。

融合 GPU 分支的四组 T9 对照虽然数值通过，包含准备的求解时间全部回退，按原规则未进入完整资格与排名。若将来有新证据并重新预登记，建议只在高档把每个 stock 臂加一个 fused 对照，同一次窗口由 40 增至 80。每个 Galerkin 配置形成调度 × 融合的 2×2，FD176 与 FD184 各有同空间融合配对。这将支持高档工程效应及交互估计。若还需中档同类结论，两档完整设计共 130 槽位。旧高档 50 条的基线为过解析 Leg39，只保留为原配置历史证据。
