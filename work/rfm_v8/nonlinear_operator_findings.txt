固定离散与 FFT 数据流

Galerkin 以每个径向节点的角向谱为输入。spectrum 从径向系数重构
u_r、u_θ、ω 的 Hermitian 半谱，包括 k=1 边界提升和独立的实值均值分量。
一次批量 Z2D 对 3q 条径向序列作逆变换。在同一物理角网格形成 u_rω 与
u_θω，一次批量 D2Z 对 2q 条序列作正变换。随后径向与角向投影分别使用
两个乘积半谱。角向因子在 k=0 为零，径向均值投影保留。隐式算子、升阶
历史与外边界提升仍按对应步长相位应用。FD4 的对应批为 4w 条逆变换和
w 条正变换，物理点积先合成一个对流项。两者每次非线性评估都调用两个
批量 FFT。两个历史缓冲已经分配，原 products 内核也已将乘积计算和
旧谱拷贝放入同一次 launch。

对实值场 f 与 g，令 C=FFT(f+i g)。精确算术中有
F_k=(C_k+conj(C_{−k}))/2、G_k=(C_k−conj(C_{−k}))/(2i)。此映射也适用于
k=0，偶长度时须同样处理 Nyquist 项。一条长度 N 的复序列携带和两条
长度 N 实序列相同数量的独立实数据。原两条实变换已在一个 cuFFT 批里，
用一次复 FFT 替代不能据 API 数量判定减少计算量，且需要频率重排或拆包。
对两个逆变换做相反的打包也需构造完整的复谱。保持原 3/2 去混叠角网格，
本轮未晋升这种替换。把乘积改写成另一种离散对流形式还涉及径向求积、
弱形式积分分部与边界处理，不能视为本轮同离散的局部优化。

试验 A。隔步计算真实非线性通量

保留恒步二阶 BDF 的隐式质量和黏性部分。过渡后只在偶数索引求真实 F，
用最近两个真实样本外推到 t_{n+1}。偶数 n 用 1.5F_n−0.5F_{n−2}，奇数
n 用 2F_{n−1}−F_{n−3}。这些权重来自一次插值。两种点位的外推误差首项
分别为 −1.5h²F″ 和 −4h²F″，普通相邻样本为 −h²F″。隐式质量、边界提升、
观测步点和初始 Euler 步均保留。t=8 后先保留两个正常更新，进入稀疏段时
已有所需的真实样本。这里只提出平滑条件下的形式一致性。

线性分裂测试 y′=λ_I y+λ_E y 中，记 a=1.5−hλ_I、z=hλ_E，
对四维历史状态 (y_n,y_{n−1},y_{n−2},y_{n−3})，偶步传播矩阵首行为
[(2+1.5z),−0.5,−0.5z,0]/a，奇步为 [2,(−0.5+2z),0,−z]/a。
两矩阵其余各行作历史移位。两步矩阵在 λ_I=λ_E=0 时的特征值模为
1、1/9、0、0。带精确历史的三组标量例显示末档收敛阶约1.998至2.016，
但误差为普通 SBDF2 的3.29至3.62倍。对无量纲实耗散 hα=0.01 的抽样，
|hβ| 增大时第一次谱半径超过 1 的网格点由0.3275降至0.2045；hα=0.1
时由0.558降至0.3355。这些只是指定标量问题的采样，无完整非线性 NS
稳定性保证，也未对连续复谱稳定域作证明。

真实流场采用 RFM37/r128 和 RFM41/r152、同一固定种子7331的原恒步
Recurrence Galerkin，目标 T=16。稠密通量控制全部完成，真实非线性调用
分别为2047和2431。两条稀疏候选分别在9.5078125和9.559210526报告乘法
溢出，均未完成资格。因此没有稀疏轨迹的精度或速度结果，也没有移植到 GPU。
最初尝试在固定态保护检查中发现我把只用于 k=1 的提升误加到所有非零模态。
旧脚本副本、两条已完成控制和冻结记录保留。独立修正批通过固定态质量位级
对照后才进入稀疏推进，报告的溢出来自该修正批。

试验 B。频谱历史缓冲交替

令 A、B 为旧有的两个相同布局设备半谱缓冲。第 n 步只将本步正变换写入
与 n 同奇偶的缓冲，另一个保留 F_{n−1}。初始两个缓冲为零，第一次输出写
入原 transformed 指针。归纳时另一缓冲始终含上一步有效频谱，所以
advance 得到与拷贝路径相同的当前/历史输入。桥接取其绝对步索引的奇偶。
重复捕获图的块长必须为偶数，剩余步按绝对索引逐个选择。浮点乘积、变换
计划、投影、观测与图中的主要算子顺序保持原样。

复用既有 products 内核，将频谱拷贝元素数设为零，不重编新内核，也不
需要额外的频谱缓冲。中档每评估名义省 2q·floor(N/2+1) 个 complex128
的读与写，即 q=66、N=225 时477312字节。该值是源码访问量，不能当作
实测显存流量。FD176 对应的名义值为683200字节，但没有移植或测速。
FFT 次数、非线性评估次数与每步 launch 数保持不变。

RFM37 种子7331的 T=9 GPU 对照共八对，包括三对等步相位、三对
128→112 分段、一个奇数桥索引和一个无图分段。保存状态、观测时刻、
速度与涡量探针均逐位一致，工作计数均一致。两组有图的推进配对中位差
为−0.030和+0.018毫秒，方向不稳定。完整求解差受到初始化漂移影响，
不能归给这个内存改动。未达到晋升要求，保留精确实现与负面诊断，未进行
长程复测或 FD 移植。

图块长度的完整时段诊断

另一个独立批次只改变 CUDA graph 块长。沿用 RFM37、Legendre37 的原组合
128→112 调度，以及 FD176 稠密恒步128。所有条目使用同一完整求解依赖，
新进程和新运行时，记录相位准备、推进、完整求解和进程至结果耗时。
24、48、64、128 四档共三组预登记随机顺序，36/36 保存数组与既有达标
归档逐位一致。没有额外数值精度假设，也没有新旧导入优化混在一个比较中。

由调度推算的 Galerkin 图启动次数为 340、170、126、62，对应图外执行的
非线性评估数为31、31、127、255，包含独立桥接步。48档将图启动数减半，
推进时间对24档的配对中位比仍仅为0.9999和1.0006。128档多用约10毫秒
捕获图，推进中位比为0.9939和0.9958。FD176 的各替代档推进中位比
为0.9963至0.9997。数值完全一致，所有替代档仍未通过预登记的诊断筛选。
保留24档。该批未做外载隔离，不能由这些比值推出稳定性能差。
